«Смета ремонта» — офлайн-калькулятор материалов для ремонта для iPhone и iPad. Приложение считает площади, количество упаковок и стоимость материалов по каждой комнате и работает полностью без сети — данные хранятся только на устройстве и никуда не передаются.
